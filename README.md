🚀 Использование

chmod +x dsh.sh

./dsh.sh           # поднять, дождаться токена и открыть браузер
./dsh.sh up        # поднять, дождаться токена и открыть браузер
./dsh.sh rebuild   # пересобрать образ и открыть браузер
./dsh.sh url       # просто вывести URL (например, для копирования)
./dsh.sh open      # открыть текущую сессию в браузере
./dsh.sh logs      # смотреть логи в realtime
./dsh.sh restart   # перезапустить и открыть
./dsh.sh down      # остановить



💡 Важный нюанс для Web-профиля

Документация dsh-command-context-trim содержит важное предупреждение: в веб-профиле автоматическая перенастройка порогов сжатия «на лету» может не срабатывать, так как агенты создаются внутри изолированной области каждой сессии. Это означает, что команда /trim и аварийное срабатывание при превышении окна (emergencyTrim) работать будут, а вот автоматическое срабатывание по достижении thresholdRatio может быть недоступно.

Практический вывод: после запуска нового контейнера обязательно создайте новую сессию. Настройки из cordis.patch.yml применяются в момент создания сессии, поэтому в старых сессиях они могут не заработать. В новой сессии плагин должен подхватить конфигурацию с порогом 0.75. Если автоматика всё же не сработает, у вас всегда останется ручная команда /trim для экстренной очистки контекста.

💡 На что обратить внимание после установки

После пересборки и запуска контейнера (docker compose down && docker compose up -d --build) в логах вы увидите, как скрипт последовательно проверяет и устанавливает каждый плагин. Некоторые из них потребуют ручной активации или настройки через веб-интерфейс DSH:

dsh-locale-russian: после установки зайдите в Настройки → Язык и выберите «Русский». Интерфейс, включая dshmarket, должен переключиться на русский.
dshmarket: после перезапуска в настройках появится раздел «Plugin Market» (или «Магазин плагинов»), где вы сможете управлять плагинами в один клик.
@goodandready/dsh-messenger-gateway: потребуется вручную указать токен вашего Telegram-бота (от @BotFather) в настройках плагина, чтобы он начал работать.
dsh-rss-digest и @shengsheng/dsh-taskboard: после установки в интерфейсе появятся соответствующие инструменты (команды для RSS и канбан-доска), которые нужно будет настроить под себя.
@hytime/dsh-thinking-effort и dsh-mnemon: их настройки появятся в соответствующих разделах панели управления плагинами
